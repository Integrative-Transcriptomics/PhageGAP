PhageGAP provides:

  • protein function prediction using protein language model embeddings and a trained classifier.
  • interactive exploration of predictions, embedding similarity, sequence alignments, structures, and genomic context.
  • confidence-aware analysis of individual proteins and complete phage proteomes.

How to use PhageGAP

Quick Start

On the Function Prediction page, follow these steps to analyze your protein sequences:
  1. Paste protein sequences or upload a FASTA file.
  2. Click Function Prediction.
  3. Explore the submitted proteins in the Embedding Landscape.
  4. Select a protein to inspect its prediction, nearest neighbor sequence alignment, and structure.
  5. Optionally add genomic context from a GFF3 file.

1) Provide Protein Sequences

Enter protein sequences directly or upload a FASTA file. If both are provided, all sequences are combined into one submission.

  • Sequences must be provided in FASTA format.
  • The first token after > is used as the protein ID; remaining text is used as its description.
  • Ambiguous amino acids are accepted and converted to X.
  • Protein IDs should be unique within a submission.
>prot_001 putative capsid protein
MNNR...
>prot_002 tail fiber protein
MDSK...

2) Run Function Prediction

Click Function Prediction to analyze the submitted proteins. Predictions are added to the current session and shown as User Data in the Embedding Landscape.

  • Cookie consent must be accepted before classification is enabled.
  • Submitted protein sequences are processed for analysis but are not persistently stored by PhageGAP.
  • Classification requests are rate-limited. If a request is rejected, wait before submitting again.

3) Explore the Results

The Embedding Landscape places submitted proteins within the embedding landscape of the PhageGAP reference dataset.

  • Reference proteins are colored by functional category.
  • Submitted proteins are shown as User Data.
  • Hover over points to inspect predictions, nearest-neighbor information, and available metadata.
  • Use the zoom controls to inspect individual regions of the landscape.

When no protein is selected, the summary view shows the distribution of the highest predicted sub-level class probabilities across the submitted proteins, separated into reference-identical and non-identical proteins.

Select a User Data point to inspect that protein in detail:

  • The selected protein is linked to its nearest reference protein in the embedding landscape.
  • Function Prediction and Nearest-Neighbor Structure shows the highest-ranked functional predictions and, when available, the structure of the nearest neighbor.
  • Nearest-Neighbor Sequence Alignment shows the alignment between the submitted protein and its nearest neighbor.
  • Alignment coloring is linked to the structure view.
  • Use the alignment zoom control and structure maximize control for more detailed inspection.

A structure may not be available for every reference protein.

4) Add Genomic Context

Use Add Genomic Context to upload a GFF3 file (.gff or .gff3).

  • Only CDS features are displayed.
  • The GFF Name attribute must match the corresponding FASTA protein ID.
  • Matched CDS features are colored according to their predicted functional category.
  • Selecting a protein focuses the genomic view on its local genomic neighborhood.

5) Save, Restore, and Export

  • Download Results exports prediction results as TSV.
  • Download Session saves the current analysis as compressed JSON (.json.gz).
  • Reload Session restores a previously saved session.
  • Screenshot exports the current analysis panels as PNG.
