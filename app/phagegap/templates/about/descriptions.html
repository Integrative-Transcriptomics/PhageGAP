Results and terms

This page explains the main items shown after you run Function Classification.

Global Embedding Landscape

  • Reference points: proteins from the built-in reference metadata, grouped by functional category color.
  • User Data: proteins from your submission.
  • Click a User Data point: opens linked details (prediction bars, nearest-neighbor alignment, structure, and optional genomic focus).
  • Nearest-neighbor link: a line is drawn from the selected user protein to its nearest reference protein.

Function Prediction values

  • top1, top2, top3: three ranked predicted labels.
  • P(top1), P(top2), P(top3): corresponding probabilities.
  • nearest_neighbor_ID: closest reference protein used for detailed comparison.
  • nearest_neighbor_distance: distance to that reference in embedding space (smaller means closer).

Nearest-neighbor views

  • Sequence Alignment: residue-level comparison between your selected protein and its nearest neighbor.
  • Structure view: nearest-neighbor 3D structure with alignment-based coloring; available quality values may include mean pLDDT and predicted TM-score.

Genomic Context

After GFF upload, CDS features are shown by genomic position and strand.

  • If a CDS Name matches a submitted protein ID, its block is colored by the predicted category.
  • Feature tooltips can show ID, locus_tag, position, strand, product, and predicted category.

Functional categories used in the interface

Reference proteins are displayed in these top-level categories:

Replication, NA processing, Structural, Assembly, Translation, Anti-Defense, Effectors, Host takeover, Lysis, Lysogeny, AMGs

Predicted labels (top1 etc.) are displayed alongside their mapped top-level category in tooltips and charts.
