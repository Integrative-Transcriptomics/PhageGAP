Cookies and Session Management

  • A consent cookie named phagegap_consent is required before API requests are accepted.
  • A server session cookie named phagegap_session is used for request protection (including only a CSRF token).

Data Handling

  • PhageGAP implements FASTA and GFF upload/submit endpoints and returns results to the client.
  • PhageGAP does not use user accounts or a database-backed storage system. Therefore, your uploaded data is not stored on our server.
  • Users can explicitly export results/session files locally from the browser via toolbar actions.
