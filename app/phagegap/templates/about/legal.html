Cookie and session use

  • A consent cookie named phagegap_consent is required before API requests are accepted.
  • A server session cookie named phagegap_session is used for request protection (including CSRF token handling).
  • Session cookie settings in this repository include Secure, HttpOnly, and SameSite=Lax.

Data handling (repository-based scope)

  • This repository implements FASTA and GFF upload/submit endpoints and returns analysis data to the browser.
  • This repository does not implement user accounts or a database-backed project storage layer.
  • Users can explicitly export results/session files locally from the browser via toolbar actions.

This summary reflects only this codebase. It does not by itself define external infrastructure policy or retention beyond this repository.
