With PhageGAP we provide:

  • an easy-to-use, free platform that predicts curated functional classes for phage proteins using protein language model embeddings.
  • confidence-aware, interactive, visual exploration of single-protein and whole-proteome analyses.
  • improved functional inference beyond direct sequence-homology transfer baselines.

How to use PhageGAP

Quick Start

  1. Paste protein FASTA text and/or upload a FASTA file.
  2. Click Function Classification.
  3. Click a User Data point in the Global Embedding Landscape to inspect category predictions, nearest-neighbor alignment, and structure.
  4. Optionally add genomic context from a GFF file.

1) Provide Protein Sequences

Enter protein sequences directly or upload a FASTA file. If both are provided, the sequences are combined into one submission.

  • Protein sequences must be provided in FASTA format.
  • The first token after > is used as the protein ID; the remaining header text is used as its description.
  • Sequence line length is not restricted.
  • Ambiguous amino acids are accepted and converted to X.
  • Use unique protein IDs to avoid ambiguous results.
>prot_001 putative capsid protein
MNNR...
>prot_002 tail fiber protein
MDSK...

2) Run Function Classification

Click Function Classification to analyze the submitted proteins. Results are added to the current session and displayed as User Data in the Global Embedding Landscape.

  • You must accept the cookie consent before Function Classification is enabled.
  • Submitted protein sequences are processed for analysis and are not persistently stored by PhageGAP.
  • Classification requests are rate-limited. If you submit again too quickly, wait and retry. If you experience rate or file size limits, please contact the listed maintainer.

3) Explore the Results

The Global Embedding Landscape provides an overview of your submitted proteins and the reference proteins used by PhageGAP.

  • Reference proteins are colored according to their functional categories.
  • Submitted proteins are displayed as "User Data" with an increased symbol size and black highlighting.
  • Hover over a User Data point to see its protein ID, highest-ranked predicted category, and nearest neighbor protein.
  • Hover over a reference point to see its functional category and available metadata.
  • Use the ZoomZoom Reset tool to select and enlarge a region of the landscape.

Click any User Data point to update linked views:

  • A line is drawn from the selected protein to its nearest neighbor reference protein.
  • Function Prediction and Nearest Neighbor Structure shows the three highest-ranked functional categories and their probabilities together with the available structure of the nearest-neighbor protein (including mean pLDDT abd predicted TM-score).
  • Use Maximize Structure View to enlarge the structure visualization and reduce the prominence of the function-prediction panel.
  • The Nearest Neighbor Sequence Alignment shows aligned residues for the selected protein and its nearest neighbor.
    • The coloring of the sequence alignment is linked to the structure view.
    • Use the zoom control above the alignment to inspect individual regions in more detail.

There may not be a structure available for all reference proteins.

4) Add Genomic Context

Use Add Genomic Context in the toolbar to upload a Generic Feature Format Version 3 (.gff or .gff3) file. CDS features are displayed by genomic position and strand.

  • Only CDS features are used. Features should provide standard 9-column GFF records with key=value attributes.
  • The GFF Name attribute must match the corresponding FASTA protein ID to link a CDS to a submitted protein.
  • Matched CDS features are colored according to their predicted functional category. Selecting a linked protein focuses the genomic-context view on its local neighborhood.

5) Save-and-Restore or Export

  • Download Results: Exports your results as TSV (phagegap-results-YYYY-MM-DD.tsv).
  • Download Session: Exports your results, selection, and genomic features as compressed JSON (.json.gz).
  • Reload Session: Restores a saved session file (.gz / .json.gz).
  • Screenshot: Saves a PNG image of the current analysis panels.
