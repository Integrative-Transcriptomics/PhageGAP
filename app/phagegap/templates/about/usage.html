How to use PhageGAP

Quick start

  1. Paste protein FASTA text and/or upload a FASTA file.
  2. Click Function Classification.
  3. Click a User Data point in the Global Embedding Landscape to inspect predictions, nearest-neighbor alignment, and structure.
  4. Optionally add genomic context from a GFF file.

1) Provide protein sequences

You can submit sequence data by text input, file upload, or both together. PhageGAP combines both inputs into one analysis request.

  • Input must contain valid FASTA records.
  • The first token after > is used as protein_ID.
  • The full FASTA header line is kept as description text.
  • Use unique protein IDs. Duplicate IDs in one submission keep only the last record; IDs already loaded in the current session are not added again.
>prot_001 putative capsid protein
MNNR...
>prot_002 tail fiber protein
MDSK...

2) Run the analysis

Click Function Classification to submit your proteins. New results are appended to your current session and shown as User Data in the landscape view.

Important: Classification and GFF uploads are rate-limited. If you submit again too quickly, wait and retry.

3) Explore the results

  • Global Embedding Landscape: shows reference proteins by category and your submitted proteins as User Data.
  • Function Prediction and Nearest Neighbor Structure: top predictions (top1, top2, top3) with probabilities, plus nearest-neighbor structure.
  • Nearest Neighbor Sequence Alignment: aligned residues for the selected protein and its nearest neighbor.
  • Selection tools: clear selection, zoom the landscape, or maximize the structure panel.

Click any User Data point to update all linked views.

4) Add genomic context

Use Add Genomic Context in the toolbar to upload a .gff or .gff3 file.

  • Only CDS features are used.
  • Features should provide standard 9-column GFF records with key=value attributes.
  • For linking to submitted proteins, the GFF Name attribute must match FASTA protein IDs.

When IDs match, predicted categories are shown on genomic features and selection in the landscape can zoom to local genomic neighborhoods.

5) Save, restore, or export

  • Download Results: exports current user results as TSV (phagegap-results-YYYY-MM-DD.tsv).
  • Download Session: exports selected protein, user results, and genomic features as compressed JSON (.json.gz).
  • Reload Session: restores a saved session file (.gz / .json.gz).
  • Screenshot: saves a PNG image of the current analysis panels.

Tips and important notes

  • You must accept the cookie consent banner before API-backed features are enabled.
  • At least one valid FASTA record is required.
  • Large requests may fail (server request size limit is approximately 500 KB).

For interpretation guidance, see Results and terms.
