Privacy and Data Handling

  • Cookies are not used for advertising, profiling, or cross-site tracking. phagegap_consent records consent required before API requests are accepted. phagegap_session is used for request protection, including CSRF protection.
  • Submitted FASTA and optional GFF data are processed for the requested analysis and are not persistently stored by the PhageGAP application.
  • PhageGAP does not use user accounts or database-backed storage for submitted sequence data.
  • Exported results and session files are generated on request and saved locally through the browser.

Standard server infrastructure may process technical connection information such as IP addresses, request timestamps, and HTTP metadata where required to operate and secure the service.
